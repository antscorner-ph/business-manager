# Ant's Corner Business Manager

A comprehensive business management system for managing daily sales, receivables, bank deposits, and purchase orders.

## Features

- **Daily Sales Tracking** - Record and reconcile daily cash transactions
- **Receivables Management** - Track customer accounts and payments
- **Bank Deposits** - Manage deposit records with itemized breakdowns
- **Purchase Orders** - Handle supplier orders and payment tracking
- **Sales History** - Review past daily sales records

## Technologies

This project is built with:

- **React** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling
- **shadcn/ui** - UI component library
- **Supabase** - Backend and database
- **React Router** - Navigation
- **React Query** - Data fetching and caching

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd antscorner-cash-reconciler

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:8080`

## Development

```sh
# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```

## Deployment

Build the project for production:

```sh
npm run build
```

The built files will be in the `dist` directory, ready to be deployed to any static hosting service.
